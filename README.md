# Zaher Madi - Portfolio & Blog

A modern React portfolio and blog website for Zaher Madi, a Software Developer and Cloud Enthusiast from Nice, France.

## 🚀 Features

- **Modern Design**: Clean, professional design with smooth animations
- **Dark/Light Mode**: Toggle between dark and light themes
- **Responsive**: Fully responsive design for all devices
- **React Router**: Client-side routing for seamless navigation
- **Reusable Components**: Modular component architecture

## 📋 Sections

- **Hero**: Introduction with animated code window
- **Who Am I**: Personal information with animated background
- **Skills**: Education, certifications, and technical skills
- **Blog**: Latest articles and tutorials
- **Projects**: Featured projects (Can I Help You, 51Games)

## 🏃 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
